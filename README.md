# Home 3D model

Interactive 3D model of an apartment, built with [Three.js](https://threejs.org/) and [Vite](https://vitejs.dev/).

**Live:** <https://main.d2i49pzpszs17n.amplifyapp.com>

## Quick start

```bash
npm install
npm run dev
```

Then open <http://localhost:5173>.
